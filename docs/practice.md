# 练习计划（Practice）——设计稿

> 状态：**设计稿**，未开工。回答三个问题：**每天 1–2 小时练什么**、**怎么练**、**学得深了练什么**。
> 落地形态是 App 里新增的「练习」页，而不是又一份乐理课。

## 0. 出发点

用户原话（2026-11-05）：

> 我常常不知道练什么、怎么去练……左手按弦要稳、和弦切换流畅，然后节奏要稳，这是最基本的，
> 然后加一些小技巧，左手滑音、击勾弦，右手扫弦、拨片。如果每天有 1–2 小时，应该练些什么？
> 随着学习加深，应该针对练哪些技巧？

拆成三件事：

| 问题 | 现状 | 这份文档给什么 |
|---|---|---|
| 练什么 | 40 关只练「音阶推算」，乐理只讲「为什么」 | 四类内容的清单 + 每项的验收标准 |
| 怎么练 | 没有方法，容易「练到时间到」 | 时间盒模板 + 三条铁律 |
| 先练什么 | 没有顺序 | 六个阶段（S0–S5），每阶段的重点与升级门槛 |

**为什么不是再来一门课**：课程解决"知道"，练习解决"手会"。这两件事在 App 里应该是两条线——
乐理页负责"懂"，练习页负责"练"，40 关作为音阶那一段的考核。

## 1. 练什么：四类，缺一不可

| 类别 | 内容 | 为什么不能省 |
|---|---|---|
| 音阶 | C 大调 1–5 品 → 换把 → 小调五声 / 布鲁斯 | 手指的地图；即兴和"找和弦音"的底座。40 关练的就是它 |
| 和弦与转换 | 16 个开放和弦、级数进行、CAGED 五把位 | 弹唱与伴奏的主体；转换卡顿是最常见的"听起来不会弹" |
| 节奏 | 时值（4 / 8 / 16 分、附点、三连音）、扫弦型、闷音、跟节拍器 | 节奏错=全错，而且是唯一"旁人一听就知道"的东西 |
| 技巧 | 左：击、勾、滑、推、揉、制音；右：交替拨弦、经济拨弦、分解、扫弦、拨片控制 | 让同样的音"像首歌"；也是速度上限的来源 |

**每天都覆盖四类，但"重点"轮换**——不是周一音阶、周二和弦。
理由：音阶和节奏靠**高频**长神经通路，隔一周练一次等于每次从零开始；技巧与曲目可以隔天，
因为它们是"整合性"练习，吃的是当天状态。

## 2. 怎么练：时间盒 + 三条铁律

1. **慢到不错**：目标速度的 60–70% 起，连续两遍不错才 +5 BPM。快而错 = 把错误练成肌肉记忆。
2. **每次只解决一个问题**：开练前写一句"今天的唯一目标"（例：换 G 时无名指不要碰到 5 弦）。
3. **完成标准是「连续 N 次不错」，不是「练满 10 分钟」**。时间到了还在磕，说明这项没练完，
   明天继续——这比"打卡成功但没长进"诚实。

配套：

- 节拍器全程开（纯手指热身除外）；
- 每周至少录音回听一次（浏览器 `MediaRecorder` 录 30 秒就够，回听能听见自己听不见的塌拍）；
- 练完记一句感受（稳 / 一般 / 不稳），一周后回看比看时长有用。

## 3. 每日模板（按可用时间缩放）

默认 60 分钟：

| 块 | 分钟 | 内容 | 完成标准（示例） |
|---|---|---|---|
| 热身 | 8 | 爬格子 1-2-3-4 / 蜘蛛 / 慢速音阶 | 60 BPM 8 分，两轮无杂音 |
| 基本功（当阶段重点） | 20 | 阶段指定：击勾滑推 / 交替拨弦 / 转换 | 按该 drill 的验收 |
| 和弦与伴奏 | 15 | 两两转换 + 今日节奏型 | 60 BPM 每 2 拍换，1 分钟不错 |
| 节奏 | 10 | 时值切换 + 扫弦型，跟节拍器 | 70 BPM 8 小节不塌拍 |
| 应用 | 7 | 和弦 + 节奏合成一段，录音 | 完整弹 1 遍不掉拍 |

缩放（取整到 5 分钟）：

| 总时长 | 热身 | 基本功 | 和弦 | 节奏 | 应用 | 曲目/即兴 |
|---|---|---|---|---|---|---|
| 30 | 3 | 10 | 8 | 5 | 4 | — |
| 45 | 5 | 15 | 10 | 8 | 7 | — |
| 60 | 8 | 20 | 15 | 10 | 7 | — |
| 90 | 10 | 30 | 20 | 15 | 15 | — |
| 120 | 10 | 35 | 25 | 20 | 20 | 25 |

120 分钟的差别不是"每块更久"，而是**多一个"整段输出"块**：长时间练习的价值在把碎片
合起来弹成一首，而不是把练习曲多弹十遍。

## 4. 六个阶段

| 阶段 | 名称 | 重点 | 必修 | 验收（升级门槛） |
|---|---|---|---|---|
| S0 | 生存 | 姿势、拨弦、按弦不碰邻弦 | 爬格子；C 大调 1–5 品单音 | 60 BPM 4 分，C 大调上下行一个八度，每个音干净 |
| S1 | 和弦 | 开放和弦 + 4 / 8 分扫弦 | C G D A E Am Em Dm；4 拍换；D-DU-UDU | 任意两和弦 60 BPM 每 4 拍换，1 分钟不错 |
| S2 | 节奏 | 时值全套 + 扫弦型 + 闷音 | 4 / 8 / 16 分、附点、三连音、3/4 与 6/8 | 40–100 BPM 跟拍不掉；8 分扫弦用手腕不用整臂 |
| S3 | 左手技巧 | 击、勾、滑、推、揉 | 五声 1–5 品连奏；推弦到准音 | 80 BPM 8 分，击勾连奏 2 小节不错音 |
| S4 | 右手与换把 | 交替 / 经济拨弦、分解、CAGED | 单弦 16 分；53231323；五把位 | 100 BPM 16 分连续 2 分钟；任意调 5 个把位 1 分钟找齐 |
| S5 | 应用 | 级数进行、布鲁斯、即兴 | I–V–vi–IV、12 小节、五声即兴 | 2 分钟伴奏 + 即兴，录音无明显塌拍 |

阶段之间**不硬锁**（沿用乐理挑战「不用锁」的决定）：默认按 40 关进度推断（L01–L08 → S0/S1，
L21 起换把 → S4 的半边），页面上可手动切换。

各阶段的块配比也不同：S0–S1 和弦与节奏占大头，S3 基本功占大头（击勾滑推要慢练），
S5 应用块最大。

## 5. App 里怎么落：四个模块

### 5.1 乐理第 12 课：时值、拍号与节奏

> ✅ 已实现（v0.8.0）：`packages/core/src/rhythm.ts` + `RhythmStrip` + `Metronome`。

- 内容：全音符 → 二分 → 四分 → 八分 → 十六分；附点；三连音；休止；拍号 4/4、3/4、6/8；
  BPM 与"一拍"的关系；**同样的音高换时值就成了另一首歌**。
- 图：一条 `RhythmStrip`（横向 4 拍，可切 4 / 8 / 16 分、附点、三连音，每拍一个高亮块），
  下面是扫弦箭头（↓ ↑）与分解和弦的 53231323 对位。
- 位置：作为**第 12 课**放末尾，并在第 1 课加一句「先记住：音有高低，也有长短，长短在第 12 课」。
  不插到第 2 位——那会让 12 节课全部重编号，且现有 `#lesson-5` 之类的锚点与检查脚本都会漂。

### 5.2 技巧库

- 14 张卡（左 7 / 右 7）：击弦、勾弦、滑音、推弦、揉弦、制音（左手）、换把；
  交替拨弦、经济拨弦、分解和弦、扫弦、闷音（右手）、拨片角度、跨弦。
- 每张卡固定四段：**是什么 / 要领 / 常见错误 / 练法（分 3 步，带 BPM 区间）/ 验收**。
- 数据放 `packages/core/src/techniques.ts`，纯数据 + 类型，插件也能复用（可选做成
  `guitar_technique` 工具）。

### 5.3 练习计划引擎 + 练习页

- `packages/core/src/practice.ts`：`STAGES`、`DRILLS`、`buildSession({ minutes, stage, focus, date })`
  → 一份按时长切好的块列表（每块带 drill、分钟数、验收标准）。
- 页面：**今日计划**（卡片列表，每卡有计时器、"开始/完成"、自评三档）→ 练完出小结
  （用了几分钟、哪块标了"不稳"）。
- 顶部一句"今天的唯一目标"（可编辑），默认由最近错误数据生成（见 §7）。
- 记录写 `guitar.practice.v1`：按天存 `{ minutes, stage, done[], feel, bpmMax }`，
  外加 `streak`（连续天数）与每周汇总。
- 统计页加「练习」分区：连续天数、本周分钟数、各块占比、最近 4 周趋势。

### 5.4 节拍器与节奏训练

- 纯函数 `packages/core/src/rhythm.ts`：时值表、拍号、细分、附点、三连音、`bpmToMs`、
  `accentPattern`（强拍/弱拍/细分音）。
- Web 侧 `useMetronome`：Web Audio 生成点击（不需要音频文件），支持重音、细分（4 / 8 / 16 分）、
  逐段加速（每 4 小节 +5 BPM）、与练习块联动（点"开始"直接带 BPM）。
- 视觉：一排拍点 + 当前拍高亮，配扫弦箭头。**视觉节拍器本身就能练节奏**（对准高亮拨弦）。

## 6. 数据模型（草稿）

```ts
export type BlockId = "warmup" | "technique" | "chords" | "rhythm" | "apply" | "song";

export interface Drill {
  id: string;               // "ham1"
  name: string;             // "击弦：五声 1–5 品，两音一组"
  block: BlockId;
  stage: 0 | 1 | 2 | 3 | 4 | 5;
  minutes: [number, number]; // 建议区间，最终由模板权重分配
  bpm?: [number, number];    // 起步 → 目标
  steps: string[];           // 3–5 步练法
  mistakes: string;          // 常见错误（一句话）
  pass: string;              // 验收：连续 N 次 / 某 BPM 某时值
  links?: { levels?: string[]; theory?: string };
}

export interface Stage {
  id: 0 | 1 | 2 | 3 | 4 | 5;
  name: string;              // "左手技巧"
  focus: string;             // 一句话重点
  must: string[];            // 必修 drill id
  gate: string;              // 升级门槛（人话）
}

export interface SessionBlock { block: BlockId; drill: Drill; minutes: number }
export interface Session { date: string; minutes: number; stage: number; goal: string; blocks: SessionBlock[] }
```

写进 core 的好处：能单测（时长加起来等于总时长、每阶段必修都在、同一天生成结果稳定），
也能被插件复用。

## 7. 联动：把"错过的音"变成今天的微练习

现有的 `AttemptResult` 已经知道每次错在哪几格。做法：

1. 记录最近 N 次尝试的错格（`guitar.progress.v1` 里加一个小的环形缓冲，只存 `s:f` 与次数，不存整份结果）；
2. `weakSpots()` 汇总出「最常错 3 格」；
3. `buildSession` 在热身块里插一条 2–3 分钟微练习：只弹这几格所在的弦/品，慢速、每个音念出来。

这是这个 App 相比"通用练习 App"最值钱的地方——它知道你在哪卡住，而练习页正好能用上。
复杂度可控，放第二期。

## 8. 实施顺序

| 期 | 内容 | 为什么这个顺序 |
|---|---|---|
| P1（v0.8.0）✅ | `rhythm.ts` + 节拍器 + 第 12 课时值 | 节奏是四类里唯一"没有音频就没法练"的，先把工具做出来；也把原 v0.9.0 的音频提前一小块 |
| P2（v0.9.0） | `practice.ts` + 练习页（计划 / 计时 / 打卡 / 自评 / 周报） | 有了节拍器，练习块才有"开始"按钮可接 |
| P3 | `techniques.ts` + 技巧库页 + 与 drill 互链 | 内容是独立的，晚做不影响 P1/P2 |
| P4 | 弱点微练习（§7）、录音回听（`MediaRecorder`） | 依赖尝试数据的存储改造 |

**壳（Tauri / Capacitor）从 v0.8.0 撤下**：工具链装不齐，占着版本号只会让路线图发虚，
改成「待工具链」的不排期项。

## 9. 明确不做

- **自动判分**：没有麦克风输入，节奏准不准、按弦干净不干净机器听不出来。用自评 + 录音回听，
  不假装能评分。
- **曲库 / 教学视频**：版权与内容成本都不在这个项目的射程内。"应用"块用级数进行与用户自选的歌。
- **每日固定曲单**（周一音阶、周二和弦）：与"高频覆盖"的原则冲突，见 §1。
- **强制解锁**：阶段可手选，和乐理挑战保持一致。
