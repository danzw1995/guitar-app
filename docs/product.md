# 产品说明

## 1. 一句话

给吉他初学者用的**指板 / 音阶练习工具**：看得懂六线谱，但不知道指板上是什么音；用 40 关渐进游戏把“音名—品位—调号”练成条件反射。

## 2. 目标用户

- 弹唱入门：会几个和弦，但换把位、找音慢。
- 准备转指弹：需要熟悉指板音名与音阶形状。
- 自学者：没有老师盯，需要即时反馈和可量化的练习。

## 3. 要解决的问题

1. 看谱能弹，但指板上每个格是什么音反应不过来。
2. 音阶记住形状，但换个调就找不到。
3. 练习没有反馈：不知道自己错在哪、快了多少。

## 4. 价值主张

- **渐进**：40 关从 C 大调 1–5 品到全把位小调，难度可量化。
- **即时反馈**：逐格判定，音高对 / 拼写错 / 错三态。
- **可比较**：计时 + 最佳成绩 + 星级；同一关所有人同题。
- **跨端**：Web 先用，后续桌面 / 安卓 / DSH 插件复用同一套核心。

## 5. v1 范围（当前 v0.3.x）

| 模块 | 内容 |
|---|---|
| 和弦库 | 16 个常用和弦，指法图、建议指法、横按 |
| 音阶指板 | 标准调弦，12 调 × 4 音阶，0–12 品，主音 / 音阶音高亮 |
| 游戏 | 40 关固定关卡，给定部分音名，推算其余；计时、判定、结果 |
| 进度 | 每关完成状态、1–3 星、逐关解锁、最快全对时间；严格拼写开关 |
| 核心 | 调号拼写、出题、难度、判定、进度与星级，纯 TS + 单测 |

## 6. 非目标（v1 明确不做）

- 账号、云同步、排行榜
- 音频识别 / 扒带 / 曲谱库
- 音频播放、节拍器（放到 v0.6）
- iOS、微信小程序（暂缓）
- 用户上传内容、社交

## 7. 成功指标（后续接入）

- 40 关完成率、平均星级
- 单次练习时长、7 日留存
- 每关平均用时下降曲线
- 拼写错误率（衡量教学效果）

## 8. 设计原则

- 一次只练一个能力：先音名，再音阶，再速度。
- 错误要可解释：告诉用户“音对了，拼写应是 Bb”，而不是只判错。
- 默认宽松、可选严格：不让拼写挡住初学。
- 手机优先：竖屏、单手持机、点按目标 ≥ 40px。
